# Recovering a canvas

A section that takes time to load shows its name and a loading message. If loading or rendering fails, **Retry section** tries that section again. Navigation, footer and the composer state remain outside the failed section. A retry can reset unfinished local edit-form state inside that section; it does not clear saved rules, history or the composer. If the installed package changed and the section remains unavailable, copy unsaved text and reopen Enhance Prompt from Copilot. There is no automatic page reload.

The canvas displays a small notice when its live event stream disconnects. It retries after 2 seconds, doubling consecutive failed attempts up to 30 seconds. **Retry connection** starts one earlier attempt; repeated clicks cannot create parallel subscriptions. Headers and an idle stream have a 45-second deadline, compared with the backend's 15-second heartbeat. Background-tab suspension can delay timers; this is not an exact outage detector. A resumed stream can trigger a safe project-status read. It never replays enhancement, sending, installation or saving requests, and cannot resume another canvas's run.

An unavailable/unauthorized canvas (HTTP 401, 403, 404 or 410) stops automatic attempts. Copy unsaved text, then reopen Enhance Prompt from Copilot. Restart Copilot only if reopening still fails. These are recovery instructions, not evidence of a live application reload. A healthy event subscription says nothing about model/account availability; that separate status remains in the composer.

Disconnected progress can miss intermediate events. The original enhancement request still owns its result or failure; starting another enhancement is not part of reconnecting. Check **Saved**, **Saving**, or **Save failed** before closing. Failed saves require the existing explicit **Retry save** action. A native close still cannot guarantee a final save; see [draft persistence](draft-saving.md).

Only sanitized operation/outcome codes reach Show Logs. No event contents, error strings, connection tokens or draft text are recorded. Each decoded event frame and incomplete suffix is bounded to 65,536 JavaScript string units (up to 128 KiB of UTF-16 text); multiple valid frames in one network read can exceed that aggregate size. Malformed streams reconnect. Closing cancels the subscription and its retry timers.

Verification uses controlled fetch/stream failures, the production transport and save queue, React server rendering plus a hook fixture for rejected-lazy-loader retry, and the existing disposable packaged runtime fixture. These do not establish native focus restoration, actual desktop restart behavior or appearance. Owner acceptance in #29 must check narrow/wide loading and failure notices, keyboard Retry, unsaved text, an update with the canvas open, and disconnect/reopen without duplicate work.
