# Getting started

Follow the local marketplace installation in the [README](../README.md). Open a project session and add the Enhance Prompt canvas.

In Models, choose a provider or detected subscription CLI. API models need that provider's key; local models may not. The model Test button makes a small real request.

Enter a rough prompt, select a style, and start with Standard context. Preview shows what project information would be included. Enhance runs the configured model chain. Review the output before Send, or Copy it for manual use.

Send targets only the session that opened the canvas. Opening a different desktop session does not retarget this panel. Busy, blocked or disconnected sessions must become idle before sending.
