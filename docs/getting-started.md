# Getting started

Follow the GitHub marketplace installation in the [README](../README.md). Open a project session and add the installed Enhance Prompt canvas.

In **Models**, add a model from the live GitHub Copilot catalog. Assign it to an effort in **Settings > Effort models**. Model names such as Claude or GPT refer to models accessed through Copilot. The model **Test** button makes a small real request using your Copilot plan.

Enter a rough prompt, select a style, and start with **Project overview** context. Preview shows what project information would be included. **Enhance** runs the configured Copilot model chain. Review the output before **Send to Copilot**, or copy it for manual use.

Send targets only the session that opened the canvas. Opening a different desktop session does not retarget this panel. Busy, blocked or disconnected sessions must become idle before sending. **Enhance and send** is a separate option that requires enabling **Send right after enhancing** in its dialog.
