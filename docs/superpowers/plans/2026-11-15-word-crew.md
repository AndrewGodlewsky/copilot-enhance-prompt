# Word crew implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan. The owner has approved the animation and implementation.

**Goal:** Ship the approved word-carrying crew, with a completion sweep that translates the entire paragraph without compressing it.

**Architecture:** Keep motion in a pure panel module and browser drawing in a small renderer. The composer observes its actual run and shows a decorative SVG over the unchanged textarea. Only real success starts the exit and sweep; ending the animation reveals the original input without writing any draft data.

**Tech Stack:** Existing TypeScript, React, SVG, requestAnimationFrame and Node tests; no new dependencies.

**Spec:** [Approved character and animation design](../../design/word-crew/README.md), amended by the owner's approval: move all text downward together, then restore the exact original request.

## Global constraints

- Preserve model inputs, drafts, results, progress reporting, privacy and sending safeguards.
- No desktop or browser UI automation, paid model calls, tags or releases.
- Approximately one 28px classic figure per ten visible words; unchanged text spacing and 2.5× preview pace.
- Respect reduced motion; failures, cancellation and disposal reveal the original immediately.
- Commit verified artifacts and push to main without force-pushing.

## Review focus

- Stale runs, tab switches and changed drafts must never overwrite or conceal newer content.
- Text measurement must preserve native wrapping; unsupported layouts must retain readable input.
- Reduced motion, resize, hidden panels and drawing errors must not leave the composer blank or locked.
- Success must translate every word by the same distance and retain 100% progress through the brief ending.
- Animation must not change enhancement or automatic sending behavior.
