# AI Test Implementation Plan

> Historical planning record. This captures the design and verification at that time; current behavior is documented in the [README](../../../README.md) and [Copilot-only plan](../plans/2026-11-15-copilot-only.md).

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add AI Test as a separate Context Level choice, with bounded iterative project research before rewriting.

**Architecture:** Keep AI-assisted unchanged. Start AI Test with Relevant code context, then broker structured model requests through the protected project reader. Use the selected effort model and its existing provider/usage route for research and rewriting; give the model no executable tools.

**Tech Stack:** TypeScript, existing Node test runner, React panel, existing background model transport. No new dependencies.

**Spec:** Owner-approved experiment: inspect project context, request further evidence, then create the prompt. Owner confirmed a new Context Level choice rather than a navigation tab.

## Global constraints

- Preserve default context, existing levels, auto-enhance, attachments, sending, and animation behavior.
- English UI and instructions. Preserve user content and Unicode.
- No desktop/browser automation or paid model tests.
- Maximum two research model calls, 45 seconds (at most half the remaining run budget), eight new file windows, 16,000 added context characters, 45,000 total automatic context characters.
- Each round permits three explicit reads and two literal searches. Searches share the existing 300-file / 4 MB / 1.5-second scan bound per round. Excerpts are at most 80 lines and 4,000 characters each.
- Reject unavailable roots, excluded/sensitive files, traversal, absolute paths, and links escaping the project. Recheck privacy before reads and model calls. Abort if privacy changes during research.
- Ordinary research failures retain gathered evidence and continue rewriting. Cancellation, changed privacy and usage-accounting failures stop the run.
- Commit verified generated assets; push main without force; no release/tag.

## Review focus

- Malformed or repeated model requests must stop safely without an unlimited retry.
- A model can request sensitive paths, external paths, or links; none may reach the next request.
- The second model call must see the first round's actual excerpts; the final rewrite must see the second round's evidence.
- Cancellation and privacy changes must prevent further model calls, including the final rewrite.
- Selecting AI Test as the default must not enable research in the chat hook or preview.
