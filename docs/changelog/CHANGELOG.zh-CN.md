# 更新记录

## [0.2.1] - 2026-11-14

### 新增
- 页脚提供仓库、设置、诊断日志和 GitHub 新建问题页面的链接。版本号显示为灰色普通文本；更新后仍会自动显示一次发行说明。
- 可复制的支持日志，包含时间、操作结果、耗时、错误代码和 Copilot 失败阶段。日志仅保存在有数量限制的内存中，不包含提示词、文件内容、路径、账户名或 API 密钥，也不会自动上传。
- 无法连接后台进程时仍可查看面板诊断信息；剪贴板不可用时可手动选择并复制日志。

## [0.2.0] - 2026-11-14

### 新增
- GitHub Copilot 预设，提供账户专属的实时模型列表，使用桌面应用现有的 SDK 和运行时进行后台改写。用户无需安装 npm、下载独立运行时或填写 API 密钥。
- 临时辅助会话验证账户和模型，禁用工具及自动项目发现，支持取消和清理。选择 Copilot 后，回退和 Max 文件选择也只使用 Copilot。

### 改进
- 新建模型表单默认选择 GitHub Copilot，保留已有配置；API 和订阅 CLI 仍可单独选择。
- 更新安装、Copilot 计费、登录和实验性运行时兼容性说明。两秒限制的聊天自动增强 hook 不使用 Copilot 后台会话。

## [0.1.8] - 2026-11-14

### 改进
- 将提示符与星光图标替换为带向上箭头的绿色 Lift 对话气泡。Copilot 插件元数据继续使用小体积 SVG，并同步更新 PNG 网站图标。

## [0.1.7] - 2026-11-14

### 修复
- 移除落后于横幅的颜色渐变过渡，让请求输入区域、通用控件和通知关闭按钮在浅色与深色之间立即切换。

## [0.1.6] - 2026-11-14

### 新增
- Quiet Desk 横幅显示 GitHub Copilot 名称，静态插图随本地时间及当前增强状态变化，无动画。
- 右上角提供单个浅色/深色切换按钮，跨画布和会话记住选择；未选择时跟随系统主题。

### 改进
- 将版本和发行说明链接移至页脚，将语言选择器放在导航旁。

## [0.1.5] - 2026-11-14

### 改进
- 移除无效的画布图标覆盖及 SDK 声明修改。Copilot 原生标签页使用所属插件的小体积 SVG 标志，与 Usage Insights 的机制一致。
- 检查插件标志的大小和画布所属插件，不再将 SDK 传递图标路径视为桌面显示成功的证明。
- 推荐使用 GitHub marketplace 的缓存安装。后续诊断发现，本地目录安装的桌面会话元数据缺少标志；切换安装来源后，同一批会话获得了正确的 SVG。仅新建会话并不能可靠修复此问题。

## [0.1.4] - 2026-11-14

### 改进
- 参照 Usage Insights 的清单配置，将 Copilot 插件标志改为小体积 SVG。面板和画布 SDK 元数据继续使用 PNG。桌面标签页的显示效果仍需手动确认。

## [0.1.3] - 2026-11-14

### 修复
- 在画布本身注册品牌图标，让 Copilot 的原生标签页显示它。兼容会遗漏图标字段的旧版内置 SDK，并通过画布发现和标签页打开事件验证。

## [0.1.2] - 2026-11-14

### 改进
- 导航增加文字标签，以“写下需求”及“审阅并发送”划分步骤，并明确显示优化、复制和发送到 Copilot 操作。
- 增大文字和控件，明确模型与上下文选项，显示键盘焦点和滚动条，并支持方向键切换分段选项。
- 改善历史、模型、规则和设置的可读性；解释无法发送的原因，以及直接优化并发送会跳过审阅。
- 更新英语、越南语和中文界面文案。保留现有快捷键、隐私检查及自动发送的主动确认机制。

## [0.1.1] - 2026-11-14

### 新增
- 新的单色提示符与星芒图标，已在 Copilot 插件元数据中声明，并显示在画布顶部和网页图标中。

## [0.1.0] - 2026-11-14

### 新增
- 原生 GitHub Copilot 画布，保留提示词编辑、模型、回退、规则、结构、历史、附件和上下文预览。
- 绑定会话的发送、经过身份验证的本地传输、持久化偏好和会话草稿，以及 Windows 保护的 API 密钥。
- 独立 Node 测试和打包的扩展。

### 变更
- 发送创建新的 Copilot 消息。会话忙碌、等待确认、断开连接或状态未知时拒绝发送。
- 自动增强是可选的会话提示词钩子，默认关闭；可能修改在 Copilot 中输入的提示词。
- 不支持的终端、编辑器和通知功能标为不可用。文件导出使用浏览器下载。
- 这是 Copilot 分支的首个发布系列。更早的开发历史保留在 Git 中。
