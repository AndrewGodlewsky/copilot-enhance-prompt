# 更新记录

## [0.1.0] - 2026-11-14

### 新增
- 原生 GitHub Copilot 画布，保留提示词编辑、模型、回退、规则、结构、历史、附件和上下文预览。
- 绑定会话的发送、经过身份验证的本地传输、持久化偏好和会话草稿，以及 Windows 保护的 API 密钥。
- 独立 Node 测试和打包的扩展。

### 变更
- 发送创建新的 Copilot 消息。会话忙碌、等待确认、断开连接或状态未知时拒绝发送。
- 自动增强是可选的会话提示词钩子，默认关闭；可能修改在 Copilot 中输入的提示词。
- 不支持的终端、编辑器和通知功能标为不可用。文件导出使用浏览器下载。
- 这是 Copilot 分支的首个发布系列。更早的开发历史保留在 Git 中。
